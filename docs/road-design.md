# 道路設計の知識ベース（インプット 2026-07-07）

出典: 国交省 道路構造令解説 / 都市計画道路の考え方（詳細リンクはチャットログ参照）

## 4つの柱
1. **設計速度が全てを決める**: 速度→最小曲線半径・最大縦断勾配・車線幅・視距が自動的に決まる
   - 80km/h: 半径280m・勾配4-6%・車線3.5m ／ 40km/h: 半径60m・勾配7-9%
2. **道路の階層**: 自動車専用道路→幹線街路→補助幹線→区画街路。家は幹線に直接面させない。上位ほど交差点を減らす
3. **横断構成**: 車道+路肩+歩道+植樹帯のレイヤー。格が高いほど断面がリッチ
4. **道路が街区を作る**: 網目80-120mのブロックが土地利用を決める。道路は都市の骨格

## 標示・付帯物（実物準拠で実装済み）
- 中央線は幅5.5m以上の道路のみ。対面通行の高速はワイヤーロープ式防護柵（暫定2車線標準）✅
- 車道外側線=白実線15-20cm ✅ / 車線境界線=白破線 ✅
- 横断歩道: バー長3m・幅45cm・間隔45cm、バーは進行方向に平行 ✅（交差点に自動描画）
- 停止線: 幅30cm・左側車線・横断歩道の手前 ✅
- 導流帯（ゼブラ）: 白縁取りの三角形+斜線 ✅ / 視線誘導標（夜発光）✅

## ゲーム世界のスケール方針
- 世界は現実の約1/5圧縮。勾配・長さは「体感の実基準」に換算して1/2〜1/3で表現する
- ランプ勾配: 実基準7-9% → ゲームでは15%（直結ランプ）/ 9%（ループは実基準相当）

## トランペットIC（2026-07-07 ユーザー選択A → 精査で v1.1）
- 降りランプ: 52m・勾配約10%・幅4.4m（ユーザー指摘でさらに延長。ループ化は本線を跨ぐフライオーバーが必要なため将来候補）
- ループはリボン曲面(BufferGeometry 61分割)でカクカク解消。ゼブラは境界線上の分岐直前へ+ノーズに緩衝クッション。出口予告板の柱は地面から
- 上りランプ: 西側に**ループ（半径11m・270°旋回・勾配約9%）**→ 高架の側道橋で北上→加速車線に合流
- 高架下通路の上を側道橋が立体交差（本物のトランペットICと同じ構図）
- ループの敷地は丘・森の生成マスクで平地化
