# ゲーム開発ノート — 「街で、いきる」プロジェクト（仮）

## コンセプト
自分でリアルな街を作れて、その街で生活できて、お店の経営（ビジネス）ができるゲーム。

## 決定ログ
- 2026-07-06 旧プロト全削除、仕切り直し
- コアループ = **いきる**（生活）。つくる・かせぐはそれを支える臓器
- 視点 = **切替式**（歩行時: 斜め見下ろし追従 ／ 街づくり時: BuildIt風上空ビュー）
- アートの北極星 = **SimCity BuildIt** の質感（彩度高・かわいい立体・砂浜と青い海）
- エンジン = **両方少しずつ**
  - 本線: ブラウザ(Three.js)で最速制作。将来必要ならGodotへ移植（設計は持ち越し可能）
  - 道場: 週1のGodotミニ課題でユーザー自身が手を動かして学ぶ
- 最初のバーティカルスライス = 検討中（次の決定事項）

## 学習ログ
- #1 ゲームの4部品: エンジン / データモデル(世界はただの表) / アセット / ゲームループ
- #2 コアループが決まると世界の作り方が逆算で決まる。バーティカルスライス=完成形の1切れを上から下まで
- #3 エンジン比較: Godot(無料/入門に優しい/BuildIt級OK)・ブラウザ(天井高い/URL共有最速)・Unity(業界標準だが学習最重量)
