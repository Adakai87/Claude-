# 市長モード（まちづくり）論点リスト v1 — すり合わせ用

階層で整理。各論点に推奨案つき。ユーザーの回答で確定していく。

## L1 土地
- 論点: 更地の初期状態は？ 完全な平地草原か、川や海辺を含む地形か。初期の広さと拡張の形。
- 推奨: 海辺＋川つきの地形（スライスの技術資産が活きる）。最初は狭い区画から拡張式（BuildIt型）。

## L2 道路
- 論点: 引き方の操作。グリッドスナップ（マス目に沿ってドラッグ）vs 自由曲線。削除・やり直し。コストの有無。
- 推奨: グリッドスナップ（BuildIt同方式・タッチで確実に気持ちいい）。最初はコスト無しのクリエイティブから。

## L3 建物と区画
- 論点: 配置ルール。「道路沿いにしか置けない」制約を入れるか。回転は？ 建設メニューの分類（住宅/商業/公共/装飾×和風/洋風…）。
- 推奨: 道路沿い制約あり（街が自然に「街の形」になるBuildItの発明）。回転は90°刻み。メニューはカテゴリ×スタイルの2軸。

## L4 操作体験（カメラと指）
- 論点: ピンチズーム・回転・パン。配置時のプレビュー表示（緑=置ける/赤=ダメ）。誤タップ対策（確定ボタン式か即置きか）。
- 推奨: パン＋ピンチズームのみ（回転なしで開始）。ドラッグでプレビュー→指を離す前に緑/赤→確定ボタン式（BuildIt同様）。

## L5 モード切替（市長⇄ダイブイン）
- 論点: どうやって街に降りる？ ボタン一発か、分身の居場所に降りるか。降りる場所の選択。
- 推奨: v1はボタン一発（タップした地点に降りる）。演出は後で磨く。

## L6 進行と経済
- 論点: 資金・資材・人口をいつから入れるか。
- 推奨: まず無限クリエイティブモードで「作る気持ちよさ」を完成させ、その後に経済を載せる（フェーズ3）。
