# ゲームデザイン文書（GDD） v0.2 — ドラフト

## コンセプト（ユーザー原文の要旨・2026-07-06）
- 舞台は**あえて指定しない**。まっさらな土地からスタートし、プレイヤーが自ら建設して世界を作る。
  建設メニューに欧風・和風など多様な建物バリエーションを用意し、プレイヤーごとに違う世界観の街が生まれる。
- 主人公は**市長**（BuildIt型）。街をどんどん作れる。さらに街に**ダイブイン**して、
  中を歩き、経営・ビジネスができる。

## 構造 — 設計原則「1つの世界、2つのレンズ」（2026-07-06 ユーザー確定）
- 世界（シミュレーション）はただ1つ。視点をまたぐ特別なギミックは作らない。
- **俯瞰レンズ（市長視点）** = まちづくりにフォーカス。上空ビュー・道路敷設・建物配置
- **ダイブインレンズ** = その街を体験・生活する。自分も住民の一人として営み（経営・生活）を行う
- どちらで時間を過ごすかはプレイヤーの自由。仕組みで誘導しない。
- つながりは「世界がひとつ」であること自体から自然に生まれる（住民が増えれば店の客も増える等）。
