# ゲームデザイン文書（GDD） v0.2 — ドラフト

## コンセプト（ユーザー原文の要旨・2026-07-06）
- 舞台は**あえて指定しない**。まっさらな土地からスタートし、プレイヤーが自ら建設して世界を作る。
  建設メニューに欧風・和風など多様な建物バリエーションを用意し、プレイヤーごとに違う世界観の街が生まれる。
- 主人公は**市長**（BuildIt型）。街をどんどん作れる。さらに街に**ダイブイン**して、
  中を歩き、経営・ビジネスができる。

## 構造
- **つくる（市長モード）** = 世界の枠組み。上空ビュー・道路敷設・建物配置・都市シミュレーション
- **いきる／かせぐ（ダイブインモード）** = 街に命を吹き込む体験。追従カメラ・店経営・生活
- 独自性の仮説: BuildItの「生産待ち時間」を**ダイブイン行動で加速できる**設計に置き換える
  （市長が自分の街で働くと街が育つ＝3本柱が1ループに接続）

## ロードマップ v2（市長フレーム）
- フェーズ1: バーティカルスライス（ダイブイン体験の証明）← 現在3/5
- フェーズ2: 市長モード基盤 — まっさらな土地・上空カメラ・道路敷設・建物配置（和洋バリエーション建設メニュー）
- フェーズ3: 都市ループ — 住宅/生産チェーン/サービス範囲/人口/税収
- フェーズ4: ダイブイン統合 — 自分が置いた街に降りる。店経営が都市の成長を加速
- フェーズ5: 磨き — 音/季節/住民関係/セーブ/スマホ最適化
