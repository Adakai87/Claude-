# 街リデザイン要件定義書 v1

## 北極星
俯瞰した瞬間「本物の街だ」と感じる密度と構造（SimCity / Cities:Skylines 寄り）。
都市ごとに地形・骨格が違い、眺めても楽しく、後から立地戦略（人通り×賃料×客層）を数値として乗せられる。

- アート方向: **SimCity/C:S寄りのリアル密度**（ユーザー決定）
- 都市の個性: **都市ごとに地形の骨格を変える**（ユーザー決定: 東京=湾と川、SF=坂と橋 など）
- ゲーム上の役割: 鑑賞 と 立地戦略 の両立（ゾーニングが両方の心臓）

## レイヤー構造（上から順に作る。下の層は上の層の"結果"）

| 層 | 内容 | 状態 |
|---|---|---|
| L0 地形 | 湾・川・埋立地・海岸線のギザギザ。都市の個性の源泉 | 🔨 プロト中 |
| L1 道路骨格 | 3階層（幹線>大通り>路地）。非碁盤・地形に沿う・橋・区画サイズ不均一 | 🔨 プロト中 |
| L2 ゾーニング | CBD→商業→住宅→水辺工業の勾配。地区ごとに建物セット/色調/密度/緑量 | 未着手 |
| L3 建物と密度 | 既存アセットを地区セットへ再編。ダウンタウンは隙間なく密に | 未着手 |
| L4 生活ディテール | 車列・信号・港クレーン・屋上設備。昼夜サイクルは実装済みを活用 | 未着手 |
| L5 数値レイヤー | L2の地区に人通り・賃料・客層カーブを紐づけ→出店戦略ゲーム化 | 未着手 |

## 進め方のルール（沼らない約束）
1. 1レイヤーずつ。前の層の承認なしに次へ進まない
2. 毎ステップ、スクショで承認をもらう
3. 性能予算: メッシュ数上限を設け、超えたらインスタンシング統合
4. まず東京1都市を L4 まで完成 → その生成系で他都市（SF/NY/パリ/ロンドン…）を展開

## プロトタイプ
- `city-proto.html` — 本体(index.html)と独立した骨格プロト。東京 L0+L1（建物ゼロ）
- 承認後、本体へ移植する
