# 経済表 v3（single source of truth）

前提: 現実5分=ゲーム1日 / 収入はゲーム内0時に1日分まとめて入金 / ⏭ボタンで次の日へスキップ可
方針: リアル円スケール + 賃料モデル（ユーザー提案 2026-07-06: 「毎時徴収はよくわからない」→何のお金かが分かる制度へ）

## レート
- 賃料: **建物投資額の 1%/日**（ユーザー選択: リアル重視のじっくり型）
  - 対象: 住宅8種 + 商業4種（パン屋/カフェ/花屋/コンビニ）
  - 対象外: 交番・木・公園・噴水・道路（コストセンター）
  - マンションは増築費も投資額に加算（投資した分だけ家賃が増える）
- 住民税: **¥1,000/人/日**（固定。v3.1でシティーズ式「税率スライダー×移住」へ進化予定）
- 初期資金: ¥2.5億 / 撤去返金: 半額

## 建物ライフサイクル（v3.1 / 2026-07-06 ユーザー決定）
- 工事期間: **小型3日 / 中型4日 / 大型5日**（コテージ・和小・モダ小・商店3種・交番=3、和中・モダ中・アパート・コンビニ=4、マンション・高級邸宅=5、公園・噴水=2、木=即時）
- 見た目: 整地(フェンス+土) → 工事囲い(シート+クレーン) → お披露目🎉（期間の前40%が整地）
- 入居: **一軒家=完成翌日に一気**、**アパート=4人/日**、**マンション=6人/日(1フロア/日)**
- 移住条件: **家の前の道路が幹線道路(西端のハイウェイ)に接続していること**（未接続=移住ゼロ。接続口2か所・撤去不可。判定は接続口からのBFS）
- 収入: 賃料は**入居率に比例**、住民税は入居済み人数分。商業はお披露目=開店から満額
- 保存: 着工日(sd)のみ保存し、状態は日数差から毎回計算（セーブv4）
- 将来(v2予定): 引越しトラック・クレーン車の演出、増築の工事期間

## マンション増築
- コスト: ¥5,000万×(現階数−1)（3→4F:¥1億 … 7→8F:¥3億、8Fまでの総増築費¥10億）
- 条件: 人口 20×現階数
- 賃料は累計投資額ベース → 増築するほど日収が伸びる

## 日送りスキップ（⏭）
- 押すと Day+1、朝8:00へジャンプ、その日の収入を即入金
- 現状は回数無制限（＝実質クリエイティブモード寄り）。チート感が強ければ「1分に1回まで」等の制限を検討

## 調整ルール
数字の変更は必ずこの表を先に更新→コードへ反映。場当たりでコード内の数字を触らない。
