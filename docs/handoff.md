## 0. 3行サマリ
- SimCity BuildIt風のブラウザ街づくりゲーム（mayor.html, Three.js単一ファイル）を、ユーザー（足立開さん・ゲーム開発初心者）と「プロのゲームクリエイター」役のClaudeで開発中
- コンセプトは「**1つの世界、2つのレンズ**」（市長視点で作り、ダイブインして住民として生きる）。最上位判断基準は「**住民の生活のディテールが主役**」
- 直近は幹線道路の品質を徹底的に磨き、Cities:Skylines式の「スプライン一括生成」システム(RoadNet)を構築。カーブ道路をプレイヤーが引ける所まで到達。次は**ランプ敷設ツールv2**

## 1. 思想（優先順に）
1. **開発思想（GDD v0.3・ユーザー原文）**: 「ここに暮らす人々のディテールを描いていきたい。生活のリアルをシミュレーションに落とし込みたい。そしてその中で自分も生活を営んでいく、ビジネスを展開していく」→ 機能の採否は「それは住民の生活のディテールを豊かにするか？」で判断（docs/gdd.md）
2. **アートの北極星**: 「**ミニチュアの街に、本物の土木の文法**」= BuildItの見た目（彩度高・かわいい・ズームインに耐える密度）× Skylinesの構造（道路階層・ICの構造美・スプライン生成）。両者は同じ祖先（SimCity 2013のチルトシフト・ミニチュア路線）なので矛盾しない（docs/art-research.md・一次情報で裏取り済み）
3. **ユーザーの判断基準**: スピード重視 / データドリブン / ワクワク感。確認は最小限で自律的に進める（CLAUDE.md）

## 2. 設計原則（血を流して学んだもの・全て docs/road-design.md に詳細）
- **大原則: 道路の構成要素はすべて「点列（スプライン）から連続生成」**。直方体を回転して並べる方式は継ぎ目で必ず破綻するため全廃した
- **RoadNet生成層**: `rnRoad(class, pts, opt)` が路面+桁+縁線+一体型高欄+継ぎ目+橋脚を一括生成。**部品の手置きは禁止**
- **導線は「進行方向が反転しない一筆書き」で先に描き、構造物は導線から逆算**（東ループ初版は導線が反転する物理破綻を犯した）
- **見た目と走行経路は同じ点列を共有**（二重定義は必ずズレる）
- **導流帯（ゼブラ）は縁線2本から張るくさび形の島**。固定テクスチャの貼り紙は禁止。出口のクッションは塗装の下流端
- **受け渡しの規律**: レール・壁は前任者が終わる座標から始まる（二重・欠けの根絶）
- **幅は段差でなくすり付け（taperGeo）**: 本線11m→車線3.2→ランプ4.4→街路3.4→タイル3.15のカスケード
- **本線直線契約**: HWXの z∈[-127,+52] は必ず直線（IC構造物と整合させるため。拡張時は一緒に広げる）

## 3. 品質プロセス（ユーザー明示の掟）
- **スタンス（ユーザー原文の要旨）**: 「システム的に完成して見えても、実際の見栄えとして現実離れしていないか・整合性が取れているかの観点で徹底的に修正する。本物の道路建築家のように。プロとして」。ソフトウェア開発の専門用語での言い訳は禁止
- **竣工検査プロトコル**: 道路変更→ `__dbg.railAudit()` 0件確認 → 接続部・端部を近接撮影（`__dbg.cam(x,z,d,pitch,yaw)`）→ 目視で粗を潰す → スクショ付きで報告
- **監査**: RAILS（箱型レール）+ RAILPL（リボン型の中心点列）× RAMP_PATHS（走行経路）の交差を機械検出
- コミュニケーションずれ防止テンプレ:【どこ/現象/理想/合格条件/守ってほしいこと】+「検査画像つきで」

## 4. 実装済みの主要システム（詳細: docs/gamedev-notes.md）
- **経済v3**: 賃料(投資額1%/日×入居率)+住民税(¥1,000/人/日)、0時入金、Day+⏭スキップ（正式なゲーム手段）。SSOT=docs/economy.md
- **建物ライフサイクル**: 整地→工事(3/4/5日)→お披露目→順次入居。着工日のみ保存(セーブは日数差から状態計算)
- **NPC住民+生活スケジュールL2**: 家と職場、6:30出勤/16:00帰宅/22:00就寝、BFS通勤。引っ越しトラック、公園派住民
- **幹線道路**: 西端の高架ハイウェイ（中心線HWX・DH=6.0・W=11）。**接続していない家には移住が来ない**（CONN=接続口からBFS）。トランペットIC×2（北=フル/東ループ降り+西ループ上り、南=出口専用ハーフ）。本線車がランプを実走して街の車に変身
- **カーブ道路v1（プレイヤー敷設・最新）**: 制御点タップ(2〜8点)→Catmull-Romリボン。通過セルをroad[]にクレームして接続/車/住民が機能。セーブv5
- その他: 2本指ジェスチャーカメラ、土地リアル化（川/丘/岩場海岸/森）、昼夜、セーブ共有パネル、roadmap.html（編集可能ガント）
