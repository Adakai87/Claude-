# Coca-Cola × フルーティス｜FIZZ診断 🥤

> **キミの“炭酸性格”、まる見え。** — 10問・約1分で、あなただけの一杯が見つかる体験型診断コンテンツ。

ミツカン フルーティス診断（[mizkan-fruitysushindan.com](https://mizkan-fruitysushindan.com/)）の構造を継承しつつ、**体験の密度**で“賞を狙えるクオリティ”へ引き上げたコラボ企画プロトタイプ。

---

## 1. 課題 — なぜ作るのか

- 診断コンテンツは飽和。**「やって終わり」では拡散しない**。
- コラボの肝は **意外性 × 自分ごと化**。「コーラに混ぜる？」の驚きを、体験で腹落ちさせる必要。
- ブランド体験として **“もう一度やりたい / 友達に見せたい”** と思わせる設計が不可欠。

## 2. 解決策 — このコンテンツ

**4つの軸であなたの“炭酸性格”を解析 → 16タイプの擬人化キャラ + 専用レシピを提案。**

ただの性格診断ではなく、**「コーラ × フルーティスのあなた専用ブレンド」という具体的アクション**に着地させることで、診断→購買・実飲までを地続きに。

## 3. 賞を狙える、3つの仕掛け

| # | 仕掛け | 効果 |
|---|---|---|
| **① 設計された16タイプ** | 4つの二択軸（刺激/癒し・定番/冒険・ソロ/みんな・直感/こだわり）の組み合わせ＝16通り。MBTI的な納得感 | 「当たってる」体験。タイプ表で**コンプ欲**も刺激 |
| **② 全編アニメーション体験** | グラスが満ちるプログレス → 注いで弾けるブレンド演出 → 結果の泡はじけ。効果音（Web Audio）まで自前合成 | 滞在時間・完了率の最大化 |
| **③ シェア画像を自動生成** | 結果を**1080×1350のビジュアルカードにその場で描画→保存**。SNS投稿の手間をゼロに | UGC前提の拡散設計 |

## 4. 体験フロー

```
スタート（浮遊するグラス）
   ↓  「診断をはじめる」
10の質問（グラスが1問ごとに満ちていく / 泡が立ち上る）
   ↓
ブレンド中…（注ぐ・泡立つローディング 2.4秒）
   ↓
結果リビール（泡が弾け、テーマカラーが一変）
   ├ 炭酸性格タイプ名 + コード + 出現率
   ├ あなた専用ドリンク（動的SVG作画）+ レシピ
   ├ 🫧 裏の顔 / 💞 相性のいいタイプ
   ├ シェア画像（保存）+ X / LINE シェア
   └ もう一度診断する
```

## 5. 16タイプ設計（4軸 × データドリブン）

診断軸は**4つの二択**。組み合わせで `K-T-P-F` のような4文字コードが決まり、16タイプに分岐。

| 軸 | A | B |
|---|---|---|
| 刺激の取り方 | **K** 刺激（強炭酸・濃いめ） | **R** 癒し（微炭酸・やさしい） |
| 選び方 | **T** 定番（王道） | **B** 冒険（限定・未知） |
| 過ごし方 | **P** ソロ（ひとり時間） | **G** みんな（共有） |
| 決め方 | **F** 直感（フィーリング） | **D** こだわり（再現性） |

→ 各タイプに **専用ドリンク名・ベース（コーラ / コーラ ゼロ）・フルーティスのフレーバー・分量レシピ・ワンポイント・裏の顔・相性タイプ・出現率** を実装済み（全16種）。

例）`K-T-P-F`＝**「ご褒美ストロング」** → *ディープ・ルビーコーク*（コーラ × ザクロ&ブラックベリー）

## 6. 技術仕様

- **構成**: 素のHTML / CSS / JS（ビルド不要・依存ゼロ）。`index.html` `style.css` `script.js` の3点。
- **画像依存なし**: ドリンクは**SVGで動的作画**、シェア画像は**Canvasで描画**。外部アセット不要で軽量・差し替え容易。
- **モバイルファースト** / レスポンシブ / セーフエリア対応。
- **アクセシビリティ**: キーボード操作（`1`/`2`キーで回答）・`aria`・`prefers-reduced-motion` 対応。
- **効果音**: Web Audio APIで合成（音声ファイル不要）。右上トグルでON/OFF、設定は保存。
- **計測**: GA4タグの差し込み口を用意（本番でID設定）。

## 7. 拡散の設計

- ハッシュタグ：`#コーラ炭酸性格診断` `#フルーティス`
- X / LINE ワンタップ共有、結果カード保存 → **Instagram ストーリーズ / TikTok 投稿**を想定。
- キャンペーン文言（抽選100名）はサンプル。実施要項に差し替え可能。
