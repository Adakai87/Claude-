# 🎯 LIFE QUEST — AIコーチ × 人生ダッシュボード × RPG

Claudeを活用した、インタラクティブな人生管理コーチングツール。
**「会話」「ダッシュボード」「RPG」の3要素を1画面に統合**したプロトタイプです。

コーチと話すだけで、ダッシュボードの5軸ステータスが動き、XPが貯まってレベルが上がり、クエストが自動生成されます。これが既存アプリにない「全部入り」体験の核です。

---

## 特徴

| 要素 | 中身 |
|---|---|
| 💬 **AIコーチ** | 朝のチェックイン・夜のふりかえり・壁打ち。Claudeが相棒として深掘りしてくれる |
| 📊 **ダッシュボード** | 健康／仕事／学び／人間関係／遊び の5軸をレーダーチャートで可視化。気分の推移も記録 |
| 🗡️ **クエスト（RPG）** | タスク＝クエスト。完了でXP獲得→レベルアップ。コーチが会話から提案もしてくれる |
| 🔥 **連続記録** | 毎日使うとストリークが伸びる |

**統合の魔法**：コーチとの会話内容に応じて、Claudeが裏で `XP・5軸ステータス・気分・今日のフォーカス・新クエスト` を自動で動かします（Structured Outputsで制御）。

---

## 使い方

1. `index.html` をブラウザで開く（ビルド不要・単一ファイル）
2. 右上の ⚙️ から **Claude APIキー** を入力
   （[console.anthropic.com](https://console.anthropic.com/) で取得）
3. コーチに「おはよう」と話しかける 🎯

データはすべてブラウザの `localStorage` に保存されます。

---

## 技術メモ

- 単一HTMLファイル（依存：Chart.js / Google Fonts のCDNのみ）
- Claude Messages API をブラウザから直接呼び出し
  （`anthropic-dangerous-direct-browser-access` ヘッダ使用）
- デフォルトモデル：`claude-opus-4-8`（設定で Sonnet 4.6 / Haiku 4.5 に変更可）
- システムプロンプトは Prompt Caching 対応、変動する状態はユーザーターンに注入
- ゲーム要素は Structured Outputs（`output_config.format`）で型安全に駆動

## ⚠️ 注意

APIキーをブラウザから直接利用する構成のため、**自分専用ツール**としての利用を想定しています。共有PCや公開環境では使わないでください。本格運用するなら、キーをサーバー側に置くバックエンドを噛ませる構成へ。
