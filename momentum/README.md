# MOMENTUM — 意志力に頼らない目標達成OS

> 続かないのは、意志が弱いからじゃない。**仕組み**が無いだけ。
> MOMENTUMは「ビジョン → 目標 → ロードマップ → 今日の一歩」を一本の線でつなぎ、
> あなたの **“勢い(Momentum)” を数値で可視化** して、止まらせない目標達成アプリです。

自己管理が苦手な人のための、**スマホ・PC・Web で使えるPWA**（インストール可・オフライン動作）。

🔗 ローカルで開く: `momentum/index.html` をブラウザで開くだけ（ビルド不要）

---

## 🧭 THE MOMENTUM METHOD（書籍のように体系化された5ステップ）

アプリがこの順番をそのまま導きます。

| # | ステップ | 意味 | アプリでの機能 |
|---|---------|------|----------------|
| 01 | **DREAM 描く** | 北極星（なりたい自分）を定める | ビジョン設定 |
| 02 | **GOAL 決める** | 年→四半期→月→週へ砕く | 目標の階層化 |
| 03 | **MAP 並べる** | 「いつ・何を」を時間軸に置く | ロードマップ（タイムライン） |
| 04 | **MOVE 動く** | 今日の“たった一歩”に落とす | 習慣化エンジン |
| 05 | **MOMENTUM 積む** | 継続を可視化しループを回す | 勢いスコア／振り返り |

### 💡 独自の発明：勢い(Momentum)スコア
物理の運動量に着想を得た 0〜100 のスコア。**動けば増え、止まれば静かに減る。**
直近の行動を加重平均し、連続記録（ストリーク）・加速/減速トレンドと合わせて、
「自己管理が苦手な人」を可視化の力で前へ引っ張ります。

## ✨ 主な機能

- **🗺️ ロードマップ** — 1ヶ月/3ヶ月/6ヶ月/1年/全体でズームするタイムライン。目標＝レーン、マイルストーン＝ノード、今日ライン付き。
- **⚡ 勢いスコア** — 継続を数値化。レベル（静止/始動/加速/巡航/超加速）と30日推移グラフ。
- **🎯 目標の階層化** — 北極星 → 期間別の目標 → マイルストーン。進捗バー自動計算。
- **🔁 習慣化エンジン** — 今日の一歩をチェック。連続記録（🔥ストリーク）。
- **📓 振り返り日記** — 気分＋ひとこと記録。続ける感情をデザイン。
- **🕸️ 人生バランス** — 8領域のレーダーチャート。
- **🏅 実績バッジ／紙吹雪演出** — 達成のたびに祝う、ワクワクするUI。
- **📱 PWA** — スマホ・PCにインストール、オフライン動作、ホーム画面起動。

## 🗂️ 構成

```
momentum/
├── index.html              販売LP + アプリ本体（単一ページ）
├── styles.css              Cosmic Ascent デザインシステム
├── js/app.js               状態管理・勢いエンジン・ロードマップ描画・全画面
├── manifest.webmanifest    PWA マニフェスト
├── sw.js                   Service Worker（オフライン）
└── icons/                  アイコン（SVG + 生成PNG）
    └── generate-icons.mjs  アイコン生成スクリプト（Node標準のみ・ネット非依存）
```

- **依存ゼロ**：外部CDN・フレームワーク・ビルド不要。バニラJS。
- **データ保存**：ブラウザの localStorage（オフライン完結）。書き出し/読み込み対応。

## 🚀 使い方 / デプロイ

### ローカル
```bash
# 単にブラウザで開くか、簡易サーバで
cd momentum && python3 -m http.server 8000
# → http://localhost:8000
```

### GitHub Pages で公開
このリポジトリは `gh-pages` ブランチを GitHub Pages に配信する設定です。
`momentum/` 一式を `gh-pages` に配置すれば `https://<user>.github.io/<repo>/momentum/` で公開できます。

### アイコンの再生成
```bash
node momentum/icons/generate-icons.mjs
```
