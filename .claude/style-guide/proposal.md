# 提案書・ドキュメントスタイルガイド

> ステータス: 初期設定（Google Docs学習前のデフォルト）

## 基本方針

- **ワクワク感を最優先**: 読んで心が動く構成にする
- **ビジュアル思考**: テキストより図・表・アイコンを活用
- **PREP法**: 結論→理由→例→結論の流れ
- **数字で語る**: 抽象的な表現より具体的な数値

## 提案書構成テンプレート

```
1. タイトル・キャッチコピー
   → 一瞬で「面白そう」と思わせる

2. 課題の定義（1スライド）
   → クライアントが抱える問題を言語化

3. 解決策の提案（1〜2スライド）
   → なぜこれが最適かを簡潔に

4. 事例・実績（1スライド）
   → 数字・ビジュアルで信頼感

5. 具体的な進め方（1スライド）
   → スケジュール・体制・費用感

6. まとめ・CTA
   → 次のアクションを明確に
```

## トーン・文体

- キャッチコピー: 短く・インパクトある言葉
- 本文: 体言止め多用、簡潔に
- 数字: 必ず単位と文脈をセットで
- 感嘆符: 使いすぎない（1スライド1個まで）

## デザイン方針

- フォント: 統一感を持たせる（2種類まで）
- 色: 3色まで（ブランドカラー + アクセント1色）
- 余白: たっぷり取る（詰め込まない）
- アニメーション: 最小限（動きで驚かせない）

## CM・広告企画書の場合

- **世界観から入る**: ターゲットが共感できるシーンを冒頭に
- **ビジュアルイメージを言語化**: 「こんな映像」を具体的に
- **SNS拡散を意識**: バズる要素・シェアされる理由を明記
- **感情ファースト**: 理屈より感情を動かすことを優先
