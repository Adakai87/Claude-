# Slackスタイルガイド

> ステータス: 初期設定（Slack学習前のデフォルト）

## 基本方針

- **スピード重視**: 長文より短文。読む時間を奪わない
- **絵文字OK**: 適度に使ってOK（読みやすさ向上）
- **箇条書き活用**: 複数事項は必ずリスト化
- **スレッド活用**: 詳細はスレッドに流す

## トーン

- 社内向け: フランク・カジュアル
- クライアント向けDM: メールより砕けた程度
- 緊急度高: 冒頭に `🚨` や `【急ぎ】` をつける

## 投稿フォーマット

### 報告・共有
```
【報告】案件名
✅ 完了: ○○
📌 課題: ○○
→ ネクスト: ○○
```

### 依頼・お願い
```
【依頼】件名
お願いしたいこと: ○○
期限: ○月○日
詳細はスレッドに↓
```

### 確認・質問
```
【確認】件名
Q: ○○について教えてください。
背景: ○○
```

## チャンネル別ルール

- `#general`: 全体共有・重要なお知らせ
- `#営業チーム`: 案件進捗・数値報告
- `#雑談`: 何でもOK、絵文字多めでOK
- DM: 個別の調整・機密情報

## 注意事項

- 重要な決定事項はDMではなくチャンネルに残す
- @メンションは必要な人だけ（@channel/@hereは慎重に）
- 送信前に足立さんの確認が必要
