# メールスタイルガイド

> ステータス: 初期設定（Gmail学習前のデフォルト）

## 基本方針

- **簡潔・明快**: 要点を先に書く（BLUF: Bottom Line Up Front）
- **丁寧だが重くない**: ビジネス敬語ベース、堅すぎない
- **行動を促す**: 次のステップを明示する

## 構成テンプレート

```
件名: [アクション/トピック]_[会社名/案件名]

お世話になっております。
TORIHADAの足立でございます。

[1〜2行で用件の核心]

[詳細・背景（必要な場合のみ）]

[ネクストアクション / お願い事項]

何卒よろしくお願いいたします。

---
足立 開
株式会社TORIHADA
adachi_kai@torihada.co.jp
```

## トーン

- 社外（クライアント）: 丁寧・プロフェッショナル
- 社内: カジュアル寄り、スピード感を大事に
- 初回連絡: やや丁寧め
- 継続案件: 端的に、スピード重視

## 件名ルール

- 長くしない（30文字以内目安）
- アクション動詞を入れる（確認依頼・ご提案・ご連絡など）
- 社名や案件名を入れて識別しやすくする

## 注意事項

- 「お世話になっております」は社外のみ
- 絵文字は使わない（メールでは不要）
- 締めは「よろしくお願いいたします」系で統一
