# チーム構成 — バーチャル秘書チーム

## 全体構造

```
秘書部（統括）
├── 作業依頼部       ← 最優先自動化対象
├── コミュニケーション部
├── 企画・提案部
├── リサーチ部
├── 営業戦略部
└── CRM管理部
```

---

## 各部署の役割

### 1. 秘書部（統括）
- タスク収集 → 優先度×重要度で整理 → 各部署へ振り分け
- 議事録 → ネクストアクション整理 → チーム連携
- 進捗管理・リマインド

### 2. 作業依頼部 ⚡ 最優先
> **最大のボトルネック。ここの自動化が最優先。**
- クライアントからの依頼を受け取る
- 作業依頼文を自動生成・送信
- フォーマット標準化・テンプレート管理

### 3. コミュニケーション部
- メール返信文の下書き作成
- リマインド文の作成
- 日程調整の補助

### 4. 企画・提案部
- 提案書のドラフト作成
- 構成案・企画案の作成
- ワクワクするアイデアの発掘・提案

### 5. リサーチ部
- トレンド調査
- データ分析・レポート作成
- 競合・市場調査

### 6. 営業戦略部
- 営業戦略の立案
- 数値分析・KPI管理
- アクションプランの策定

### 7. CRM管理部
- Salesforceへの入力・更新
- データ整備・クレンジング
- レポート抽出・集計

---

## タスク振り分けフロー

```
新規タスク入力
    ↓
秘書部：優先度（高/中/低）× 重要度（高/中/低）でマトリクス分類
    ↓
該当部署へアサイン
    ↓
実行 → 下書き/成果物を提出
    ↓
足立さん確認（送信・投稿系のみ）
    ↓
完了・記録
```
