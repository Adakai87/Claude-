# 日程調整ワークフロー — Googleカレンダー連携

> 担当: コミュニケーション部（→ `.claude/team.md`）
> セッションで「日程調整」「打ち合わせを入れたい」「候補を出して」等の依頼を受けたら本フローに従う。

---

## 基本方針

- **スピード重視** — 候補は具体的な日時で即提示し、確定までの往復を最小化する
- **具体的に** — 「来週あたり」ではなく「6/2(火) 14:00〜」のように明確に出す
- **先回り** — 下書き・候補提示まではこちらで自動的に進める

---

## 4ステップフロー

### STEP 1: 空き時間検索

- 自分の予定確認・コンフリクト検出 → `list_events`（対象期間を指定）
- 複数人で合わせる → `suggest_time`
  - `attendeeEmails`: 自分は `primary`、相手はメールアドレスを指定
  - `durationMinutes`: 所要時間（既定 60 分）
  - `preferences`: `startHour` / `endHour` / `excludeWeekends`
- 対象カレンダーが不明なときは `list_calendars` で確認

### STEP 2: 候補提示

- **3〜5件**を箇条書きで提示（曜日つき・タイムゾーン明記）
- 例:
  - 6/2(火) 14:00〜15:00
  - 6/3(水) 10:00〜11:00
  - 6/5(金) 16:00〜17:00

### STEP 3: 調整メール下書き

- `create_draft` で作成（**下書きは自動作成OK / 送信は最終確認後**）
- 文面は `.claude/style-guide/email.md` に準拠（BLUF・件名ルール・署名）
- 候補日時を箇条書きで記載し、「ご都合のよい日時をお知らせください」で締める

### STEP 4: 確定後のカレンダー登録

- 相手の日時確定後、**必ず足立さんの最終確認を取ってから** `create_event`
- 設定項目:
  - `summary` / `startTime` / `endTime`（必須）、`timeZone`: `Asia/Tokyo`
  - オンライン会議は `addGoogleMeetUrl: true`
  - `attendeeEmails` に相手を追加、必要に応じ `location` / `description`

---

## リスケ・キャンセル対応

- 対象イベント特定 → `get_event`（または `list_events` で検索）
- 日時変更 → `update_event`（**最終確認後**）
- 取り消し → `delete_event`（**最終確認後**）
- 先方への連絡が必要なら `create_draft` で変更・お詫びの下書きを用意

---

## 送信・確認ルール（厳守）

CLAUDE.md「送信・投稿ルール」と整合させること。

| アクション | ルール |
|---|---|
| 空き時間検索（list_events / suggest_time） | 自動で進めてOK |
| 候補提示 | 自動で進めてOK |
| 調整メール下書き（create_draft） | 自動で進めてOK |
| 予定登録（create_event） | **必ず最終確認後に実行** |
| 予定変更（update_event） | **必ず最終確認後に実行** |
| 予定取消（delete_event） | **必ず最終確認後に実行** |
| メール送信 | **必ず最終確認後に実行** |

---

## 既定設定（依頼ごとに上書き可）

- タイムゾーン: `Asia/Tokyo`
- デフォルト所要時間: 60 分
- 営業時間目安: 09:00〜18:00 / 週末除外
